Delete Sync Account

Use this page to delete the remote Inner Breeze sync account on the default server. Offline app data on your device is not changed.

Required Proof

This deletion requires the exported inbe-sync.key file from Inner Breeze. Current exports include the sync public ID automatically. The key is sent over HTTPS to the sync server only to prove ownership and delete the account. It is not stored.

If you lost the exported key, this page cannot delete the remote sync account. Delete local app data from your device settings or from the app's local data controls.

Account Deletion

What Gets Deleted

The default sync server removes the remote account and its mirrored sync data for the public ID inside the exported key, including sessions, meditation logs, habits, habit days, photos and synced preferences. It stops using them at once and keeps them for 30 days, so importing the same key into Inner Breeze can bring them back; then it deletes them permanently, including from backups. Your local device data, exported backups, and donation records are not part of the sync account.
