Install with APT

Debian, Ubuntu and their derivatives can install Inner Breeze from its signed APT repository. New releases then arrive with your other system updates. The repository has packages for amd64 and arm64.

Add the repository

sudo curl -fsSLo /usr/share/keyrings/breeze-archive-keyring.gpg https://breeze.waozi.xyz/apt/breeze-archive-keyring.gpg
sudo curl -fsSLo /etc/apt/sources.list.d/inbe.sources https://breeze.waozi.xyz/apt/inbe.sources
sudo apt update
sudo apt install inbe

Start it from your app menu or with breeze. The signing key fingerprint is 70C3 0C13 CB00 6C50 9B19 1480 BC01 11C7 1342 0287.

Remove it

sudo apt remove inbe
sudo rm /etc/apt/sources.list.d/inbe.sources /usr/share/keyrings/breeze-archive-keyring.gpg

Your practices and habits stay in ~/.local/share/inbe.
