# Changelog

## [2.1.62] - 2026-11-03

- 추천 코드로 친구를 초대하세요. 유효한 코드를 수락하면 구매 없이 즉시 20 Dew를 받습니다. 초대한 친구가 Dew를 구매하면 5%의 Dew를 받고, 수락한 모든 사람과 수락 날짜를 확인할 수 있습니다.
- 모든 게임과 기본 앱을 유지하면서 Arcade 라이브러리 이미지를 256픽셀 WebP 썸네일로 줄입니다.
- Arcade와 라이브러리 이미지를 오프라인으로 사용할 수 있으며 게임은 별도로 다운로드합니다.
- 모든 기본 앱을 유지하고 앱 선택을 바꾸지 않으면서 1 MB 미만의 완전한 앱도 포함합니다.

- 추가 숨기기·표시 오버레이 없이 하나의 이동 손잡이로 앱 순서를 편집합니다.
- 목록을 성공적으로 저장하면 목록 설정을 닫습니다.
- 습관 보상에 탄산음료, 커피, 버블티, 초콜릿, 양초 사진을 선택할 수 있습니다.
- 알림이 더 오래 표시되며, 알림 권한과 제공업체 설정에 따라 앱을 닫아도 습관 알림이 작동합니다.
- 백업에는 항상 비밀번호가 필요합니다. 보호되지 않은 키 저장을 제거하고 Android 기기 백업이 계정을 복사하지 않도록 했습니다.
- 친구 추가 시 “이 작업을 시작할 수 없습니다” 오류가 발생하던 문제를 수정했습니다.
- 백업 파일과 비밀번호로 로그인하고, 백업 이름에 사용자 이름을 사용하며, 새 백업을 항상 비밀번호로 보호합니다.
- 친구에서 공통 프로필 페이지를 열며 친구 간 Dew 선물을 제거했습니다.
- 여기에서도 waozi.xyz 사이트 간에 계정이 이어지며 모든 사이트에서 로그아웃할 수 있습니다.
- Google Play 버전은 Google Cloud 설정 후 Google Drive로 암호화된 계정 백업을 저장하고 열 수 있습니다.
- 로컬 빌드를 반복할 때마다 새 사본을 보관하는 대신 저장 공간을 재사용합니다.
- Linux에서는 서명된 APT 저장소에서 설치하고 apt로 업데이트할 수 있습니다.
- Android 계정 키 가져오기에서 키 파일과 관련 백업 형식만 표시합니다.
- 연습 결과에 부드러운 표정, 기분 이름, 명확한 선택 상태를 표시합니다.
- 앱 격자 카드의 점 세 개 메뉴는 편집 중에도 그대로 유지됩니다.
- Telegram을 통해 전달된 Lumi 메시지에 출처를 표시합니다.
- 설정에서 각 휴식 유형을 접고 클릭해서 펼칠 수 있습니다.
- Linux 휴식 알림의 텍스트와 진행 막대를 별도 행에 표시합니다.
- 카탈로그 게임에서 자체 업적을 수여하고 평소처럼 오른쪽 위에 알림을 표시할 수 있습니다.
- 친구, 목록, 요청에 각 친구가 어떤 앱에서든 선택한 프로필 사진을 표시하며 추상 이미지도 지원합니다.
- 프로필 사진은 다른 앱과 같은 방식으로 친구에게 전달되며 직접 선택한 뒤에만 전송됩니다.
- 다른 앱에서 선택한 프로필 사진이 내 프로필에도 표시됩니다.
- 연습의 음성 안내를 다운로드하는 동안 사진이 깜박이지 않습니다.
- 태양 경배 음성 안내가 모든 자세를 말하고 각 런지에서 어느 다리인지 알려 줍니다.
- 태양 경배는 자세 요령, 뒤로 내딛는 다리와 다음 자세를 안내하고 첫 회차 전 준비 시간과 마지막 회차 후 휴식을 제공합니다.
- 태양 경배의 다음 자세를 가운데에 차분한 한 줄로 표시합니다.
- 시작할 때 연습을 아직 불러오는 중이어도 호흡과 종소리 신호가 재생됩니다.
- 이전 전체 다운로드가 도중에 멈췄어도 동기화가 복구됩니다.
