# Changelog

## [1.2.3] - 2026-10-21

- Track zero-occurrence goals and choose custom coins, including 0 and negative coins per occurrence.
- Give each achievement its own meaningful icon.
- Maintenance release for Inner Breeze 2.1.38.

## [1.2.2] - 2026-10-21

- The shop scrolls to the final activity row at phone and desktop sizes.
- Rewards can use a soda can symbol.

## [1.2.1] - 2026-10-20

- Maintenance release for Inner Breeze 2.1.37.

## [1.2.0] - 2026-10-19

- The shop now comes with Habits, so it can improve with a Habits update.
- Requires Inner Breeze 2.1.36 or later.

## [1.1.2] - 2026-10-18

- Save, discard and delete confirmations use consistent controls and can
  improve with Habits updates while preserving existing habit data.
- Requires Inner Breeze 2.1.36 or later.

## [1.1.1] - 2026-10-18

- Leaving a habit with unsaved changes asks whether to save, discard, or
  keep editing. Unchanged habits close without a prompt.

## [1.1.0] - 2026-10-17
