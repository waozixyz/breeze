Lumi's navigation glyph is an outlined firefly with antennae and wings.
Its 1.6-unit rounded stroke in a 24-unit view box matches the app's navigation
icons. sidebar.shape uses Kryon's vector icon format, so the sidebar applies
the same size and foreground color as other buttons. sidebar.svg contains the
same path; sidebar.png is its 64-pixel transparent export for navigation bars.
The full-color conversation avatar remains mascot.png.
