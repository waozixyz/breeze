# Sub-app icons

One outline mark per sub-app, generated by `scripts/app_icons.py` from the
`SUB_APPS` table in that script. Every mark is one SVG path in a 24-unit
view box drawn with a 1.6-unit rounded stroke:

- `assets/<app>/sidebar.shape` - the Kryon vector icon (`S1.6rr:` plus the
  path) that the host navigation, the app packages and the Apps launcher
  draw.
- `assets/<app>/sidebar.svg` - the same path for outside uses.
- `assets/apps/icons/<app>.png` - 64-pixel white export for the launcher
  catalog and outside uses. `assets/lumi/sidebar.png` repeats Lumi's for
  the host picture loader.

The root package carries every catalog shape as
`assets/apps/icons/<app>.shape`, so the Apps screen shows each sub-app's
own mark before its package downloads. After changing a shape, run
`python3 scripts/app_icons.py` and commit every export together with it.
